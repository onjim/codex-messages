# Codex 折叠渲染 (codex-messages)

把模型每轮回答里的**中间旁白、思考、工具调用**收进一个可展开分组——生成中显示「工作中」，完成后显示用时并**自动折叠**，只留最终答案平铺，对齐 Codex 客户端的折叠语义。

> **辨析**：本插件只改消息的**显示分组**，不改任何消息数据；与宿主内建的「思考过程」折叠不同——内建折叠只收起单条 thinking 块，本插件把**整轮**的旁白 + 思考 + 命令合并成一个分组，折叠后看到的标题就是那句旁白（如「我准备读配置并跑测试」），展开才是推理和命令明细。

## 效果

```
折叠前：旁白₁ → 思考 → 命令 → 旁白₂ → 思考 → 命令 → 最终答案   （一轮 7 条平铺）
折叠后：┌ ✂ 我准备读配置并跑测试 · 用时 12.3s ▸ ┐              （1 个分组，可展开）
        └ 最终答案普通气泡平铺 ┘
```

## 安装（插件不进 npm 包，随仓库分发）

```bash
pi-web-ui install onjim/codex-messages
```

装完刷新页面即可，设置面板「界面插件」里能看到它。不需要时 `pi-web-ui uninstall codex-messages` 或删除目录，消息回退为原生平铺渲染，无需任何配置开关。

## 它是怎么工作的

- 优先采用服务端标注的 `phase`（`commentary` / `final_answer`）作为分组依据，属权威判定；
- 宿主消息没有 `phase` 时按结构推断：仍带工具调用 → 中间旁白；只剩正文 → 最终答案；纯思考 → 并入同轮分组；
- 用户消息 / 系统消息 / 压缩摘要作为轮次边界，打断归组；仅做 DOM 层面的显示分组，不重写消息数据。

## 边界与限制

- 折叠不删除内容：点分组标题即可展开查看全部推理与命令；
- 推断有歧义的轮次（如超短回复）宁可不折叠，保持原生平铺；
- 只作用于聊天消息流，不影响会话数据、导出与 API。
